# pipeline/

Scripts used to build the database, as run, with their logs. Extraction requires an Anthropic API key and the source PDFs, which are not distributed. The portal is generated by the code in `../build/`.

## Scripts, in run order

| Stage | Scripts | What they did |
|---|---|---|
| Search and retrieval | `harvest.py`, `get_papers.py`, `download_biorxiv.py`, `missing_papers.py` | queried PubMed and Europe PMC, resolved open-access full texts, downloaded PDFs and built worklists for manual retrieval |
| Keyword screen | `filter_library.py` | scored titles and abstracts; recorded verdicts in the three screening lists |
| Extraction | `extract_exm.py` (first pass), `extract_exm_v2.py` (second pass, expanded schema), `retry_failed.py`, `fix_pass2.py` | `claude-sonnet-4-6` read each PDF and wrote rows; failed or truncated papers were retried |
| Species and clades | `normalize_species.py`, `normalise_species_names.py`, `standardise_species_detail.py`, `enrich_taxonomy.py`, `fix_clades.py` | merged species names and assigned clades |
| Reagents | `normalise_antibody_names.py`, `normalise_primary_targets.py`, `normalise_secondaries.py`, `normalise_by_reference.py`, `normalise_dye_names.py` | matched antibody, target and dye names to canonical forms |
| Suppliers | `fix_suppliers.py`, `fix_suppliers_v2.py`, `fix_suppliers_full.py`, `recover_unknown_suppliers.py` | recovered missing suppliers and catalog numbers with `claude-haiku-4-5` |
| Protocol fields | `fix_variants.py`, `fix_multi_protocol.py` | standardized ExM variant names and split multi-protocol rows |
| Duplicates | `qc_check.py`, `resolve_duplicates.py`, `flag_duplicates.py`, `check_duplicates.py` | ran consistency checks and flagged candidate duplicate pairs, classified them with CrossRef, and confirmed them with `claude-sonnet-4-6` |
| Supplementary data | `enrich_mikus_s1.py` | added the species reported only in Mikus et al. Table S1 |
| Taxonomy check | `check_clades_ncbi.py` | first version of the NCBI concordance check (see `../QC/07_ncbi_clade_concordance/`) |
| Final curation | `curate_20261009.py` | merged preprint–publication pairs, removed two reviews and restored metadata (changes in `../data/curation_log_20261009.csv`) |
| Final curation, addendum | `curate_20261019.py` | merged one further preprint–publication pair (changes appended to the same log) |

## Logs

`logs/` holds the run logs (search, retrieval, keyword screen, both extractions, failures, duplicate decisions) and the three screening lists (`library.csv`, `library_rejected.csv`, `library_needs_review.csv`).

## Use of AI

Extraction and duplicate confirmation used `claude-sonnet-4-6` and supplier recovery used `claude-haiku-4-5`, both through the Anthropic API, one paper at a time and without cross-paper context. The prompts are embedded in the scripts that call the models.
